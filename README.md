# SQL Mission 2 – Database Querying

## Project Overview

This project documents 10 SQL queries using Employees and Departments sample tables. It covers basic data retrieval, filtering, sorting, aggregate functions, grouping, conditional statements, and joins.

## Queries Covered

1. SELECT Basics – Retrieve all employee records.
2. WHERE Filter – Find employees in the IT department.
3. ORDER BY – Sort employees by name in ascending order.
4. COUNT – Count the total number of employees.
5. GROUP BY – Count employees in each department.
6. AVG – Calculate the average employee salary.
7. MAX – Find the highest employee salary.
8. MIN – Find the lowest employee salary.
9. CASE – Classify employees into High and Low salary levels.
10. LEFT JOIN – Combine employee records with department information.

## Project File

`SQL Mission 2 - Database Querying.xlsx`

The spreadsheet contains 10 SQL queries, their purposes, sample results, and documentation status. It also includes Employees and Departments sample data.
